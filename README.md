Shadowline — a top-down stealth game set in the Marrowgate Museum after dark. Sneak past patrolling guards and their vision cones, hide in the shadows, steal the Moonstone Idol from the vault, and slip out the exit unseen. Running makes noise that draws guards to investigate; getting fully spotted raises the alarm and the guards give chase.

## Run it

```sh
python3 -m http.server 8000 --directory game
```

Then open http://localhost:8000 in a desktop browser. Move with WASD or the arrow keys, hold Shift to sneak. The entry program itself runs with `MAKEFUN_OUTPUT_DIR=out node main.ts`, which copies the game and its screenshots into the output directory and writes `dossier.json`.
